# Exemplos reais de frontend da Nora

Estes arquivos foram extraídos da pasta `app/static` de uma versão de revisão do projeto Nora disponibilizada para este portfólio.

- `nora-mobile-menu.js`: interações do menu móvel, categorias, navegação e estados de acessibilidade.
- `nora-mobile-menu.css`: estilo e comportamento responsivo do mesmo menu.

**Não constituem um aplicativo independente.** Fazem referência ao HTML, estados e funções do projeto original. A intenção é mostrar um recorte do trabalho com JavaScript e CSS sem publicar o servidor, banco de dados ou tokens. Use como material de leitura técnica, não como aplicação pronta para instalação.
