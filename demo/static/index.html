Esta demonstração não é a Nora completa

Este repositório apresenta um recorte público executável para avaliação de competências com Python, FastAPI, JavaScript, CSS, HTML, persistência SQLite, testes e interface responsiva.

O aplicativo Nora principal contém recursos adicionais de acessibilidade, rotina, APIs, organização e protótipo Android, documentados no README.

Privacidade: esta demo não contém contas reais, dados de saúde, chaves, banco original ou integração Gemini. Ela é destinada apenas a execução local.
